## Installation

Install any of the pricing components directly into your project via the CLI:

```bash
# Install Pricing 01 (Grid Cards Pricing)
npx synapse-ui@latest add pricing-01

# Install Pricing 02 (Segmented Toggle pricing)
npx synapse-ui@latest add pricing-02
```
