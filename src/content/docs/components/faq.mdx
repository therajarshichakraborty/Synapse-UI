# FAQs

FAQs are structured accordion elements used to answer commonly asked questions regarding products, services, billing, or security.

Browse all the interactive FAQ designs and variants included in Synapse UI.

## Installation

Install any of the FAQ components directly into your project via the CLI:

```bash
# Install FAQ 01 (Simple Grid Accordion)
npx shadcn@latest add http://localhost:3000/r/faq-01.json

# Install FAQ 02 (Segmented Details List)
npx shadcn@latest add http://localhost:3000/r/faq-02.json
```
