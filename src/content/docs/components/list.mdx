# Lists

Lists display records, notifications, feeds, steps, or activity histories in clean vertical layout grids.

## Installation

Install any of the list components directly into your project via the CLI:

```bash
# Install List 01 (Simple Info List)
npx shadcn@latest add http://localhost:3000/r/list-01.json

# Install List 02 (Vertical Steps List)
npx shadcn@latest add http://localhost:3000/r/list-02.json
```
