Pricings help users compare subscription tiers, highlighting key details, billing frequencies, and features.

## Installation

Install any of the pricing components directly into your project via the CLI:

```bash
# Install Pricing 01 (Grid Cards Pricing)
npx shadcn@latest add http://localhost:3000/r/pricing-01.json

# Install Pricing 02 (Segmented Toggle pricing)
npx shadcn@latest add http://localhost:3000/r/pricing-02.json
```
