## Requirements

- React 19 or later
- Tailwind CSS v4
- TypeScript (recommended)

<Steps>

### Create a project

Start a new Next.js app, or skip this step if you already have one.

<PmCommand dlx="create-next-app@latest my-app --typescript --tailwind --app" />

### Set up shadcn/ui

Synapse UI installs into projects that use shadcn/ui. If yours does not yet, run this once. It creates `components.json` and the `cn` utility.

<PmCommand dlx="shadcn@latest init" />

### Add the Synapse design tokens

<PmCommand dlx="synapse-ui-cli@latest init" />

### Add components

Add components by name. Dependencies are resolved for you. Web components go to `components/synapse-ui/`, React Native components to `components/native/`.

<PmCommand dlx="synapse-ui-cli@latest add button card spotlight" />

Or add every React component and block at once:

<PmCommand dlx="synapse-ui-cli@latest add --all --react" />

Plain `--all` detects your project: React Native apps get every native component, everything else gets every React one. Use `--native` for only React Native, or `--both` for both. See the [CLI](/docs/cli#add-everything) for details.

### Import and use

```tsx title="app/page.tsx"
import { Button } from "@/components/synapse-ui/button";

export default function Page() {
  return <Button>Get started</Button>;
}
```

</Steps>

## Manual installation

Prefer to wire things up yourself? Do these steps once.

<Steps>

### Install the base dependencies

<PmCommand install="class-variance-authority clsx tailwind-merge lucide-react motion radix-ui tw-animate-css" />

### Add the `cn` utility

```ts title="lib/utils.ts"
import { clsx, type ClassValue } from "clsx";
import { twMerge } from "tailwind-merge";

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```

### Add the design tokens

Copy the tokens from [Theming](/docs/theming) into `app/globals.css`.

### Configure path aliases

```json title="tsconfig.json" {4-6}
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```

</Steps>

## Using the shadcn CLI

Every Synapse component is also published in the shadcn registry format, so the shadcn CLI can install it straight from a URL, into the same folders:

<PmCommand dlx="shadcn@latest add https://synapse-ui-dev.vercel.app/r/button.json" />

See [CLI](/docs/cli) for `all.json`, `all-native.json` and the `@synapse` namespace.
