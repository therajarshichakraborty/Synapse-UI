## Usage

```tsx
import { ExpandableCards } from "@/components/synapse-ui/expandable-card";
```

```tsx
<ExpandableCards
  items={[
    {
      id: "a",
      title: "Aurora",
      subtitle: "...",
      cover: "linear-gradient(...)",
      content: <p>...</p>,
    },
  ]}
/>
```

## Accessibility

The expanded card is a modal with `role="dialog"`. It locks body scroll and returns focus to the card that opened it.
