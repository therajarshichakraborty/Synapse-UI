## Usage

```tsx
import { DottedWorldMap } from "@/components/animated/dotted-world-map";
```

```tsx
<DottedWorldMap
  connections={[{ from: { lat: 37.77, lng: -122.42 }, to: { lat: 51.5, lng: -0.12 } }]}
/>
```

## Accessibility

Rendered as one labelled image. With reduced motion, arcs appear fully drawn and points do not pulse.
