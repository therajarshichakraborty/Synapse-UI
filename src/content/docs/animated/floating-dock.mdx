## Usage

```tsx
import { FloatingDock } from "@/components/animated/floating-dock";
```

```tsx
<FloatingDock items={[{ title: "Home", icon: <HomeIcon />, href: "/" }]} />
```

## Accessibility

Each item is a link or button labelled by its title, and the title shows on focus too. With reduced motion, items do not magnify.
