Synapse UI is **not a dependency you install**. It is a set of components you add to your project, then read, change and keep. Every component is a single TypeScript file built on Tailwind CSS v4 design tokens, Radix UI behavior and Motion animation.

<Callout type="tip" title="New in this release">
  More than 30 animated components, 12 production-ready blocks, and a rebuilt dark-first design
  system. See the [changelog](/docs/changelog).
</Callout>

## What's inside

- **Core components.** A full shadcn-compatible set (Accordion through Tooltip), re-themed with Synapse tokens. The APIs match shadcn, so existing knowledge transfers directly.
- **Animated components.** Spotlights, beams, auroras, marquees, number tickers, floating docks and more. Each one respects `prefers-reduced-motion`.
- **Blocks.** Complete sections (heroes, pricing, testimonials, auth pages, a dashboard shell) composed from the components above.
- **Collections.** Hand-crafted variants of common patterns (AI inputs, alerts, buttons, cards, FAQs) you can drop in as they are.

## Principles

### Own the code

Components are copied into your repo, so you control every class name and line of logic. Upgrades never break your app.

### Tokens, not hardcoded colors

Every color comes from a semantic CSS variable such as `--primary` or `--muted-foreground`. Re-brand the whole library by editing one file. See [Theming](/docs/theming).

### Accessible by default

Interactive components are built on Radix UI primitives, so you get correct ARIA attributes, focus management and full keyboard support. Each component page documents its keyboard interactions.

### Motion with restraint

Animations use ease-out curves, stay between 150 and 400ms in UI, and turn off entirely when the user prefers reduced motion.
