---
title: Theming
description: One set of CSS variables controls color, radius, surfaces and effects across every component.
---

Synapse UI uses semantic tokens. Components never reference a raw color. They use utilities like `bg-primary`, `text-muted-foreground` and `border-border`, which map to CSS variables.

```tsx
<div className="bg-card text-card-foreground border border-border" />
```

## Convention

Each surface token has a matching `-foreground` token for text on top of it. For example, `--primary` is the background of a primary button and `--primary-foreground` is its label.

## Token reference

| Token                                       | Purpose                                                 |
| ------------------------------------------- | ------------------------------------------------------- |
| `--background` / `--foreground`             | Page background and default text                        |
| `--surface-1` … `--surface-3`               | Three elevation levels for panels and canvases          |
| `--card` / `--popover`                      | Cards, menus, dialogs                                   |
| `--primary`                                 | Brand blue for primary actions, active states and focus |
| `--secondary` / `--accent`                  | Quiet buttons and hover states                          |
| `--muted` / `--muted-foreground`            | Subtle backgrounds and secondary text                   |
| `--destructive` / `--success` / `--warning` | Status colors                                           |
| `--border` / `--border-strong` / `--input`  | Hairlines, hover borders, form controls                 |
| `--ring`                                    | Focus rings                                             |
| `--radius`                                  | Base radius; `sm` to `4xl` are derived from it          |
| `--chart-1` … `--chart-5`                   | Chart series colors                                     |

## Brand scale and gradient

A full `brand-50` to `brand-950` scale is available as Tailwind colors (`bg-brand-500`, `text-brand-300`). The signature gradient runs cyan to blue to indigo:

```tsx
<h1 className="text-gradient">Ship faster</h1>
<div className="bg-brand-gradient h-1 w-full" />
```

## Effect utilities

| Utility                              | Effect                                                            |
| ------------------------------------ | ----------------------------------------------------------------- |
| `glass`                              | Translucent surface with backdrop blur and an inner top highlight |
| `surface-card`                       | Card background, hairline border and highlight                    |
| `bg-grid` / `bg-dots`                | Grid or dot patterns (`--grid-size`, `--dot-size`)                |
| `mask-radial-fade` / `mask-top-fade` | Radial masks that fade patterns at the edges                      |
| `border-beam`                        | Animated conic gradient border                                    |
| `noise`                              | Very low-opacity noise texture overlay                            |
| `text-gradient`                      | Brand gradient text                                               |

## Adding a token

```css title="app/globals.css"
:root {
  --info: #0891b2;
}
.dark {
  --info: #22d3ee;
}

@theme inline {
  --color-info: var(--info);
}
```

You can now use `bg-info`, `text-info` and `border-info`.
