<ComponentInstall name="native-fab" />

## Usage

```tsx
import { Fab } from "@/components/native/fab";
```

```tsx
<Fab
  actions={[
    { icon: "camera", label: "Scan", onPress: scan },
    { icon: "edit", label: "New note", onPress: create },
  ]}
/>
```

## Accessibility

Reports `expanded` when it has a menu. Tapping the scrim closes it.
