## Usage

```tsx
import { Button, IconButton } from "@/components/native/button";
```

```tsx
<Button rightIcon="arrow-right" onPress={next}>Continue</Button>
<IconButton icon="heart" accessibilityLabel="Like" />
```

## Accessibility

Uses `accessibilityRole="button"` and reports `disabled` and `busy` states. Icon-only buttons must have an `accessibilityLabel`.
