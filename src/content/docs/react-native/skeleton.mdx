## Usage

```tsx
import { Skeleton, SkeletonText } from "@/components/native/skeleton";
```

```tsx
<Skeleton circle={44} />
<SkeletonText lines={3} />
```

## Accessibility

Every skeleton on screen pulses from one shared clock, so they stay in sync and cost a single animation.
