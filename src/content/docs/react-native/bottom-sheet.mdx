## Usage

```tsx

```

```tsx
<BottomSheet open={open} onOpenChange={setOpen} title="Share" snapPoints={[0.4, 0.9]}>
  …
</BottomSheet>
```

## Accessibility

Drag the handle or header. A fast downward fling closes it from any snap point.
