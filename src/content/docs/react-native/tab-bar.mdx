## With Expo Router

```tsx
<Tabs
  screenOptions={{ headerShown: false }}
  tabBar={({ state, navigation }) => (
    <TabBar
      items={state.routes.map((r) => ({ key: r.name, label: r.name, icon: icons[r.name] }))}
      value={state.routes[state.index].name}
      onValueChange={(name) => navigation.navigate(name)}
    />
  )}
/>
```
