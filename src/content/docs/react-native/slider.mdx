## Usage

```tsx
import { Slider } from "@/components/native/slider";
```

```tsx
<Slider value={volume} onValueChange={setVolume} formatValue={(v) => `${v}%`} />
```

## Accessibility

Uses the `adjustable` role and supports increment/decrement accessibility actions (swipe up/down in VoiceOver).
