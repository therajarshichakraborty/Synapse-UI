## Usage

```tsx
import { Toaster, toast } from "@/components/native/toast";
```

```tsx
// once, at the root
<Toaster />;

// anywhere
toast.success("Saved", { description: "IMG_2048.HEIC" });
toast.promise(upload(), { loading: "Uploading…", success: "Done", error: "Failed" });
```

## API Reference

### toast

`toast(title, options)`, plus `.success`, `.error`, `.warning`, `.info`, `.loading`, `.promise` and `.dismiss(id?)`.

Up to three toasts stack with depth. Swipe up to dismiss.
