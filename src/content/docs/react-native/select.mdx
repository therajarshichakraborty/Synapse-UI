## Usage

```tsx
import { Select } from "@/components/native/select";
```

```tsx
<Select
  title="Country"
  options={[{ value: "us", label: "United States" }]}
  value={country}
  onValueChange={setCountry}
/>
```

## Accessibility

The trigger is a combobox with an `expanded` state; the Android back button closes the sheet.
