## Accessibility

Icons are decorative. Give the pressable that wraps an icon an `accessibilityLabel`.

## Adding icons

The set is generated from Lucide. Add names to `scripts/generate-native-icons.mjs` and run `node scripts/generate-native-icons.mjs`, or paste any Lucide icon node into the `icons` map.
