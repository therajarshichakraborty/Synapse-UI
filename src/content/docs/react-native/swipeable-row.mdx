## Usage

```tsx
import { SwipeableRow } from "@/components/native/swipeable-row";
```

```tsx
<SwipeableRow rightActions={[{ label: "Delete", icon: "trash", onPress: remove }]}>
  <ListItem title="Message" />
</SwipeableRow>
```

## Accessibility

Actions are exposed as accessibility actions, so screen reader users can trigger them without swiping.
