## Installation

Install any of the FAQ components directly into your project via the CLI:

```bash
# Install FAQ 01 (Simple Grid Accordion)
npx synapse-ui@latest add faq-01

# Install FAQ 02 (Segmented Details List)
npx synapse-ui@latest add faq-02
```
