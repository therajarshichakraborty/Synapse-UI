Cards are content containers used to display summaries, product highlights, user reviews, or analytical dashboard metrics in structured grids.

## Installation

Install any of the card components directly into your project via the CLI:

```bash
# Install Card 01 (Dashboard Stat Card)
npx synapse-ui@latest add card-01

# Install Card 02 (Feature Highlight Card)
npx synapse-ui@latest add card-02

# Install Card 03 (Hover Elevated Card)
npx synapse-ui@latest add card-03
```
